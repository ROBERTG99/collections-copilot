# Evaluation rules

- Datasets are generated by `data/generator/evals.py` (seed 4242) with labels by construction; committed files are append-only by version (`*.v1.jsonl`). Edits to existing test partitions are blocked by the PreToolUse hook.
- Tune prompts only on the `dev` split; the `test` split is for reporting.
- Thresholds in `evals/suites/*.yaml` only rise. Never lower one to get green.
- `evals/REPORT.md` is generated by `scripts/eval_report.py`; never edit it by hand. Every number states its mode (offline or live).
